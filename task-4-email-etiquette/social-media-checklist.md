
The "Do’s" (Best Practices)
[ ] Do Remove Gridlines: Go to View > Show > Gridlines (uncheck) for a clean, dashboard-like look.

[ ] Do Use Alternating Colors: Use Format > Alternating colors to make rows easier to read without manual shading.

[ ] Do Freeze Header Rows: Use View > Freeze > 1 Row so your column titles stay visible when scrolling.

[ ] Do Use Professional Fonts: Switch from the default Arial to modern fonts like Lexend, Inter, or Roboto.

[ ] Do Use Vertical Alignment: Set all cells to "Middle" alignment so text doesn't hug the bottom of the cell.



The "Don’ts" (What to Avoid)


[ ] Don’t Use High-Contrast Colors: Avoid neon yellow or bright red backgrounds; stick to pastels or "soft" tones for better readability.

[ ] Don’t Over-Merge Cells: Merged cells often "break" when converting to Markdown; try to keep a standard grid for your data.

[ ] Don’t Manually Draw Borders: Instead of thick black borders around every cell, use subtle bottom borders for headers only.

[ ] Don’t Leave Columns Extra Wide: Resize columns to fit the data (Double-click the column edge) to keep the sheet compact.
